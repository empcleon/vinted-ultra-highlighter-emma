# Vinted Ultra Highlighter – Emma Edition
Script avanzado para Tampermonkey que detecta chollos en Vinted de forma automática.

## Funciones principales
- Resalta artículos con palabras clave como “nuevo”, “etiqueta”, “urge”, “mudanza” o “sin usar”.
- Marca con borde rojo artículos extremadamente baratos.
- Funciona en tiempo real sin recargar la página.
- Optimizado para el nuevo feed dinámico de Vinted (2025).

## Instalación
1. Instala Tampermonkey en tu navegador.
2. Haz clic en este enlace RAW para instalar el script:
   https://raw.githubusercontent.com/empcleon/vinted-ultra-highlighter-emma/main/vinted-ultra-highlighter.user.js
3. Tampermonkey preguntará si quieres instalarlo.
4. Pulsa **Instalar**.
